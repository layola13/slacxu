# Vendor logos

These local SVG assets were generated from the `Mono` components in
`@lobehub/icons` 4.0.2, the same icon source used by Sub2API's
`frontend/src/components/common/ModelIcon.vue`.

- Upstream: https://github.com/lobehub/lobe-icons
- Package: `@lobehub/icons@4.0.2`
- License: MIT, copied in `LICENSE.txt`
- `google.svg` uses the upstream multicolor `Color` component.
- Other assets use the upstream `Mono` component and Sub2API's vendor color map.
