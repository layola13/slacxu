## 转换约定（本单元）
- string -> (ptr,len) 对；number -> f64；boolean -> bool；bigint -> i64。
- Array/Record/unknown/any/一般联合 -> (ptr,len) JSON 文本或切片 buffer；元素/成员类型仅注释保留。
- 字符串字面量联合 -> u64 标签（取值表在注释）；判别联合 -> 变体 struct + wrapper(variant + JSON payload)。
- 可选/可空 -> 普通字段（无 presence 标记；行尾 // optional in TS）；字段名与 SLA 关键字冲突者原样保留。
- class/interface -> struct + fn 家族；顶层 const 复合字面量 -> 注释逐字保留 + 按需手写物化函数。
- 函数体：shared 包为手写语义转换；协议包为纯类型文件（无函数体）。async/throw 在 SLA 侧以状态码/bool 返回近似，均在行内注 DEFECT。
