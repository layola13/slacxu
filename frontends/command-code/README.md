# cxu-frontend-command-code

Web-side plugin project for the `command-code` backend (Command Code
CLI). Implements `@cxu/sdk-frontend`. Its backend pair is
`cxu-backend-command-code`. Runtime plugin id stays `command-code`.

This is a later-phase stub created in Phase 1: the descriptor data is
real (labels/icons/classification), but the plugin's web contributions
are wired by the host's current static integration. The waterfall
compaction brand for Command Code threads is declared here
(`waterfall.compactionLabel = "Command Code"`).
