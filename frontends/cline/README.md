# cxu-frontend-cline

Web-side plugin project for the `cline` backend (Cline CLI). Implements
`@cxu/sdk-frontend`. Its backend pair is `cxu-backend-cline`. Runtime
plugin id stays `cline`.

This is a later-phase stub created in Phase 1: the descriptor data is
real (labels/icons/classification), but the plugin's web contributions
are wired by the host's current static integration. The waterfall
compaction brand for cline threads is declared here
(`waterfall.compactionLabel = "Cline"`).
